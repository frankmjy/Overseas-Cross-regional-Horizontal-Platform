## 本地迭代

登录页静态文件修改后会立即生效，Node 后端模块不会自动重载。修改认证或项目上下文后，需核对本地 3333 进程并重启，再读取 `/api/auth/session`，确认返回两项目的 `projects` 和 `loginEnabled`；不能只看页面更新就判定登录正常。

登录页项目入口位于左上角品牌区。项目读取失败显示明确终态和“重试”；未选择项目时保持登录按钮禁用。本轮已完成本地真实飞书授权、回调及泰国项目上下文验证；发布状态以正式发布台账为准。

应用 ID / Secret 沿用既有服务器本机应用配置（或 FEISHU_APP_ID / FEISHU_APP_SECRET 环境变量）。不要将凭据写入此目录。更换应用 ID 会让旧会话失效。

## 会话与记录

- 马进宇通过定盘星已核验账号进入 `/admin`；管理员按 `application.json` 的 App ID 与 Open ID 联合判断，禁止按姓名或客户端角色标识授权。
- 管理员页面包含登录访问与现有应用配置。登录历史从上述正式多维表完整分页读取，合并本地待同步事件；仅管理员可搜索、筛选、分页及刷新。浏览器不接收 Open ID、会话令牌或密钥。
- 应用配置沿用既有验证、持久化、重复提交保护及跨应用队列门禁。远程保存另外要求管理员会话、同源和 CSRF；初始化配置入口仍受本机限制。
- 本轮按老马要求不写入更新推送卡片、不发送相关群通告；GitHub 源码推送继续暂缓。

- `.runtime/auth/ledger.json` 原子保存状态、会话摘要、登录记录和同步任务，需与其他运行数据一起备份，禁止提交仓库。
- 会话有效期 12 小时，OAuth 请求 10 分钟且仅消费一次。Cookie 为 Secure / HttpOnly / SameSite=Lax；写请求要求同源，退出另校验 CSRF。
- 不保存飞书 access_token、code、App Secret、IP、邮箱、设备指纹。只有已经通过飞书身份接口验证的姓名和 Open ID 可以进入会话与记录。
- 登录先持久化事件及同步任务，再返回会话。每 30 秒检查待办，失败指数退避，最长 1 小时；按登录编号找回不确定写入并语义回读，避免重复记录。
- 超过 90 天的本地已同步事件在下次登录时清理，正式表记录保留。未同步事件不因年龄丢弃。
- 现有健康检查脚本若把公开业务接口的 HTTP 200 当作启动依据，需要在未来发布预检中适配认证后的接口或 `/api/auth/session`，不能关闭鉴权来迁就旧检查。本次未修改发布框架或生成发布包。
