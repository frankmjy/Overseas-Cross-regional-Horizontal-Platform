# VNET Node.js 统一证书中心 1.0.0-rc1（待服务器验收）

适用域名：`sm.sjhl.online`、`www.sm.sjhl.online`。保留 3001、3333、8787 及后续 Node.js Web 业务端口。要求各项目 Node.js 20 或以上；安装器会检查当前运行的 Node 版本，不会自动升级它们。

## 原理与覆盖范围

通过服务器级 `NODE_OPTIONS` 预加载统一 TLS 运行层。首次安装后需要服务器重启一次，让现有服务管理器和进程继承环境。之后，由标准 Node.js HTTP、HTTPS、HTTP/2 API 创建的公网 Web 监听统一使用中心证书；本机 loopback HTTP 和普通 TCP 服务保留原协议。既有 HTTPS 配置里的证书会由中心证书覆盖。TLS 最低版本 1.2，原应用更严格的 1.3 下限继续保留。

更新证书时，中心校验域名、日期、私钥匹配、证书用途和系统默认可信链，写入不可变版本目录，再原子切换 `current.json`。运行中的各进程约 2 秒内更新 TLS 上下文；新连接使用新证书，已建立的连接继续工作。无效候选不会替换当前有效证书。

这不是操作系统对任意端口的 TLS 强制：主动清除/覆盖 `NODE_OPTIONS` 的启动器、不读取服务器全局环境的容器、Node 内置调试器、其他技术栈和原生 TCP 服务均不在自动覆盖范围。新服务必须保留统一预加载项；使用独立服务账号时，需要对中心私钥授予该账号读取权限。不能为达到“所有端口”而把内网数据库、调试端口或原始 TCP 协议擅自公开。

## 服务器首次安装

交付包分为外层双击入口和内层 `payload.zip`。外层先验证内层 SHA-256 和压缩路径，再自动提权；内层安装器逐文件校验冻结清单。包内不含证书、私钥、应用配置或业务数据。源码目录缺少 `manifest.json` 时安装器拒绝运行。

1. 将整个交付 ZIP 复制到 Windows 服务器并解压，双击 `Start.bat`，允许 UAC 提权。无须提前停服务或打开 PowerShell。
2. 选择 3001 当前使用的同一份证书 ZIP；也可由运维传入证书和私钥路径。私钥不要上传聊天、加入代码包或日志。
3. 安装程序保存旧环境变量、保留原有 NODE_OPTIONS，安装自动更新任务。
4. 安排服务器重启一次。安装器不会自行重启服务器，也不会逐个停止业务进程。
5. 重启后双击外层 `Verify.bat`。验收会检查 3001、3333、8787 和新增的公网 Node 监听，对两个域名分别核对 TLS 信任、协议和中心指纹，并检查运行文件、环境变量和后台任务。生成 `tls-verification-日期时间.json`；只有 `passed: true` 才表示本次服务器验收通过。随后在浏览器打开各项目检查正常使用。

固定中心路径：`C:\ProgramData\VNET\TLSCenter`。

- `versions/<版本>/fullchain.pem`、`privkey.pem`：受 ACL 保护的不可变证书版本。
- `current.json`：当前版本元数据，不包含私钥。
- `inbox/fullchain.pem`、`privkey.pem`：自动更新输入。
- `install-state.json`：旧环境及恢复信息。
- `watch-status.json`：最近一次导入结果。

默认仅 SYSTEM、管理员、安装用户有完全权限；现有 Node.js 服务账号有读取权限。普通本地用户不会因此获得私钥权限。安装失败会恢复已经更改的环境及其注册表类型，并取消本次创建的任务，保留受限目录内的恢复材料。若操作人员随后改过环境或同名计划任务，自动恢复会停止并标记 `recovery-required`，避免覆盖后续操作。

## 后续换证

推荐双击外层 `UpdateCertificate.bat`，选择新证书 ZIP。工具校验后原子切换活动版本，全部已纳管进程自动更新，不重启应用。更新后可再次运行 `Verify.bat`。

也可让现有证书续期工具将完整链和私钥更新到 `inbox` 的两个固定路径。后台任务自动识别内容变化；两文件暂时不匹配时保留旧版本，匹配且校验通过后生效。这是自动应用更新，并不代替向 CA 申请或续签证书。到期前必须提供新的有效证书。

## 卸载与恢复

双击外层 `Uninstall.bat`，使用原安装管理员账号授权提权。它只在安装台账、路径和环境仍匹配时恢复原环境；遇到操作人员后续改动会停止，避免覆盖。恢复后重启服务器一次。证书、版本和恢复台账保留，不自动递归删除。

## 验证限制

开发机仅使用隔离子进程、临时测试证书及独立的临时 HKCU 测试键，不写开发机的真实系统环境、不安装计划任务、不重启开发机。环境恢复测试使用真实注册表读写适配层和替代的计划任务操作；尚未进行服务器 SYSTEM 计划任务、UAC、全局安装、重启与恢复演练。因此本包是待服务器验收的配置候选，不代表已完成服务器配置，也不作为已通过生产安装的热包。

本方案不替代 CA 证书续签。2026-10-17 服务器预检显示 3001 当前证书将于北京时间 2026-12-16 05:59:59 到期；3333 和 8787 分别仍使用 2026-08-17、2026-10-16 UTC 到期的旧证书。首次安装后必须完成重启与验收，否则运行中的旧进程仍可能返回旧证书。
