# 甘特逐条插入、删除与排序编号

目标：每个真实条目右侧提供编辑者专属操作菜单，可在下方插入同层条目、删除可删除条目；组末尾新增继续可用。插入和软删除后，显示编号按同层排序自动连续计算，源记录ID、来源编号和关联不变。

方案：增加可空条目排序(number)与显示编号(text)两列，旧记录以原来源编号作为初始顺序；新条目由后台分配相邻排序值。服务端和前端使用同一排序/编号函数；源编号保持历史身份，显示编号经持久化后台任务同步到飞书。字段缺失时旧读取兼容，顺序插入明确拒绝，不伪造同步。
