# 管理员鉴权配置

范围：管理员页面增加人员与页面权限矩阵。页面为项目管理、调研工作台、开办物资、人员储备、知识共享、议事航迹；项目管理内部视图共用该页面权限。马进宇按已核验应用与Open ID保留完整管理权限。其他已登录人员默认只读开办物资，管理员可分别配置访问和编辑，编辑必须包含访问。

沿用飞书会话与本地登录台账，将权限按App ID、Open ID持久化到同一原子台账，不修改飞书源数据权限。人员从成功登录记录及现有登录表缓存获取。所有业务API在统一鉴权入口检查，未知API默认拒绝；知识共享与议事航迹共用读取接口时裁剪无权限模块。管理员变更校验同源、CSRF、修订号、幂等标识，不能通过显示姓名、请求头或客户端数据成为管理员。撤权对后续请求立即生效。
