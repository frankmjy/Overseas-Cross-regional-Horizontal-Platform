# 平台页面鉴权

入口：管理员配置 → 鉴权配置，`/admin?tab=permissions`。人员来自当前飞书应用的成功登录记录及现有登录多维表缓存；搜索在本地完成，刷新人员使用既有缓存同步。

| 身份 | 默认访问 | 默认编辑 |
|---|---|---|
| 马进宇（已核验本项目应用 + Open ID） | 所有页面及管理员配置 | 全部 |
| 其他飞书鉴权人员 | 开办物资 | 无 |

管理员可分别配置项目管理、调研工作台、开办物资、人员储备、知识共享、议事航迹。项目管理内部总览、甘特、周跟进、月回顾和组织视图共用项目管理权限。勾选编辑会同时开启访问；关闭访问会关闭编辑。管理员自身权限固定，避免误锁。

权限按 App ID + Open ID 存入原有 `.runtime/auth/ledger.json` 的 access 区域，以原子文件更新保存，不以姓名匹配。备份和部署必须保留该台账；台账及登录信息不进 Git。管理员保存具有 CSRF、同源、修订号与持久化幂等保护；保存响应丢失可重试同一提交。不同浏览器修改冲突时重新读取，不覆盖新版本。

会话只保存身份，每个业务请求重新检查权限，撤权不需要等待原会话退出。登录后优先返回已有且允许访问的页面，否则进入可访问页面；全部权限关闭时明确提示联系管理员。前端隐藏无权限导航与写操作，后端独立阻断接口请求、附件上传、同步重试等写操作。共用的知识与会议读取接口按授权模块裁剪数据。新增业务 API 必须在路由策略中登记，普通用户默认无法使用未登记 API。

权限在平台页面级生效，并继续遵守原有项目隔离；不会修改用户在飞书原生多维表中的 ACL。人员离职或应用可用范围调整仍由飞书管理，不能用平台编辑权限代替飞书授权。

本轮仅本地完成。代表性浏览器测试使用隔离 HTTPS 端口、临时登录台账与虚构物资服务，不向真实业务表写测试记录；自签测试证书仅用于隔离测试上下文，不更改正式 TLS 校验。

2026-11-03 后续入口调整（待统一发布）：裸根地址 `/` 跳到 `/login`；直接打开 `/login` 保留登录和项目选择界面，即使已有会话也不自动跳进业务页。带明确 returnTo 的业务登录回跳保持生效。调研工作台独立为 `/research`，带项目或筛选条件的旧根路径书签跳到该地址并保留允许的筛选；默认OAuth完成后优先进入项目管理，无权限时进入允许的页面。
