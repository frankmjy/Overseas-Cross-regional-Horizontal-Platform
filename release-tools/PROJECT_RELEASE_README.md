# 海外协作平台一键升级 20261026.3

基线：用户已确认部署成功的 20261026.2。安装时仍会校验服务器真实运行锚点、旧事务及待同步台账；本机验收不代表远程服务器实测。

本版包含：
- 优化授权后进入调研工作台的体验：立即显示品牌连接动效，清单不再等待后台任务查询；独立资料读取改为两条并行链，保留对象映射顺序，异常和长等待均有重试入口，支持窄屏和减少动态效果。
- 修复统一证书中心合法换证后被旧审计指纹阻断的问题：从已启用中心的当前证书元数据及不可变证书版本核对指纹，仍校验证书链和域名，安装过程中证书来源发生变化则停止；未启用证书中心时继续使用原基线指纹。
- 飞书应用迁移至“定盘星” cli_aa547c8de6785ce2；新应用的正式及 localhost 回调已登记，服务器需使用新应用密钥。独立一键配置 BAT 与热包分别交付，使用新版 BAT，不再运行旧版。
- 人员缓存按应用隔离；有未同步任务时不允许直接跨应用切换，旧应用登录记录不使用新应用重放。历史发布回执保留原有应用与收件人配对，新文件通过新应用发送。
- 飞书授权登录及登录记录；登录页与平台导航优化。
- 调研专题进度、条目筛选排序、文字编辑及多维表同步，人员配置横向对比。
- 泰国人员架构、确认人数及人员清单，滚轮缩放和画布拖动。
- 甘特条目编辑、今天居中、日期拖动、追加跟进历史、立即保存及后台同步、每日零点刷新状态。
- 知识共享与独立议事航迹，统计图表、会议筛选及纪要正文阅读；手动新增三类会议，持久化后后台同步并核对回读，支持重试与防重复。
- 多维表已配置海外团队名录及协同资料归档，泰国/马来/协同资料表均有存放链接。名录中的权限字段仅作预配置，本版未启用角色细分鉴权。

安装：
1. 将 ZIP 复制到服务器，在项目目录外解压。
2. 双击 InstallProject.bat 并允许管理员提权，无需提前停服务或手工覆盖文件。
3. 安装器校验内层 SHA-256、源码和依赖，检查未完成事务与待同步操作，保存原字节后切换。失败时恢复旧文件和旧服务。
4. 成功后访问 https://www.sm.sjhl.online:3333/ 并使用飞书登录，按 Ctrl+F5 刷新页面。

安装报告：项目 .runtime/release-reports/20261026.3.json。失败时保留并回传报告，不要删除事务、维护锁或恢复目录。

保留服务器 .env、certs、整个 .runtime、应用凭据和外部数据目录。事务与回滚逻辑保持不变；安装健康检查的证书校验已按本次修复重新验收。无新依赖，不重装飞书 CLI，不改变 TLS 中心，不影响其他服务端口。

包不含密钥、证书、生产账本或本机业务导出。安装验收使用隔离外部调用，避免写入真实飞书业务数据。
