固定采集目录：`C:\ai\overseas-project-management-deploy-20260605-163554`。

将本包复制到服务器解压，双击 `ServerReleaseAudit.bat` 并允许管理员读取。结束后，把同目录生成的 `overseas-release-audit-日期时间.json` 回传。无须停止服务、重启服务器或打开 PowerShell。
